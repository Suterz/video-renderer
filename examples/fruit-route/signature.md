# Pocket Cutouts
## Illustration
Original simple editorial cartoon illustration on a clean ivory field: plum irregular ink outlines, red fruit, ochre woven basket and subtle petrol-teal shadows. One isolated, complete, unobstructed object per cutout, with no writing, arrows, labels, numbers or decoration on the blank background.

## Renderer-only graphics
Draw explanatory arrows in gold with dark outlines using computed object and part positions. Use bold, contrasting captions with a separate backing; no exact letters should be generated by the image model.
