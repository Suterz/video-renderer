# V4 first-attempt release rules

Freeze both runtimes, prepared payloads, model paths/revisions, configuration,
and judge before the fresh run. One POST per scheduled case; terminal refusal
on valid input does not pass. Empty or unjudged outputs remain in denominators.
Save initial failures and all bounded internal repair attempts. No scored rerun.
Preserve the frozen score separately from regressions.

An independent evaluator inspects the actual encoded opening, phone frame
before the answer, answer frame, and final hold. Verify exact quantities,
units, topology, references, narrated facts and chronology. Verify that source
evidence is visible while asked to decide. Trace the specific named part in a
close-up and phone view, not just the parent mask. When the lesson claims a
movement, verify the subjects/props changed in the intended way, not merely
their labels. Machine and agent image checks do not certify listening quality.

Fresh H01 compares rates for two supplies, H02 exact equal fractions, H03
offset ruler endpoints, H04 selected route and merge, H05 spout vs handle,
H06 displaced-volume diagram, H07 three-part stacked usage, H08 state hold,
H09 character turning while retaining an object, H10 time across noon.
Retain original word order and exact rates/units. In H06 both tank widths
and initial water levels must match; compare levels only with both blocks
fully submerged. In H09 the actual turn and the star's side must agree.
